# Signal Processing Analysis Project

This project focuses on signal processing techniques using wavelet transform and feature fusion methods. It aims to extract meaningful features from datasets and analyze them using different approaches.

---

## 📁 Project Structure

```

project-folder/
│
├── dataset/           # Raw data used in the project
├── features/          # Extracted features
├── main.py            # Main execution file
├── main_wavelet.py    # Wavelet-based processing
├── main_fusion.py     # Feature fusion implementation
├── rapor.pdf          # Detailed project report

````

---

## 🚀 Features

- Signal preprocessing  
- Wavelet transform analysis  
- Feature extraction  
- Feature fusion techniques  
- Modular Python implementation  

---

## 🛠️ Technologies Used

- Python  
- NumPy  
- Pandas  
- Signal Processing Libraries  

---

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/pelinglmz/signal-processing-analysis-project.git
````

2. Navigate to the project folder:

```bash
cd signal-processing-analysis-project
```

3. Run the main file:

```bash
python main.py
```
